# Game Studio 42

This repository holds the [organization profile](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) (`profile/README.md`) shown on https://github.com/gamestudio42.

The studio site is https://gamestudio42.github.io/.
Guerrilla posts live in [LAUNCH.md](LAUNCH.md).
Upload `profile/avatar-512.png` as the organization avatar
(Settings → Profile — GitHub has no API for that).

## Community project proposals

Games and game-development technologies can be proposed for shared maintenance or
community adoption. See the [submission guide (English / Português)](docs/PROJECT_SUBMISSIONS.md)
and [propose a project](https://github.com/gamestudio42/.github/issues/new?template=project-submission.yml).
The issue form becomes available after it is merged into the default branch.
