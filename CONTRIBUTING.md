# Contributing to Game Studio 42

Thank you for helping build open-source games.

1. Read the target repository's README, LICENSE, AGENTS.md and development instructions.
2. Open an issue or discussion before large features or changes to architecture.
3. Submit focused pull requests with tests, documentation and reproducible validation steps.
4. Keep code and technical documentation in English unless the project specifies otherwise; player-facing content may be localized.
5. Identify all third-party code, artwork, music, fonts and models with provenance and licenses. Do not add materials without redistribution rights.
6. Respect project names, logos, attribution and community conduct rules.
7. The [CLA policy](CLA.md) is **in draft**. Signing and mandatory CI enforcement will begin only after legal approval, a named steward and an operational signing process are announced. Until then, repository maintainers must verify contribution permissions individually.

See [licensing](LICENSING_POLICY.md) and [trademarks](TRADEMARK_POLICY.md).
